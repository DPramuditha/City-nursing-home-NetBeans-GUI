# 🏥 City Nursing Home Management System

## 📋 Overview

The **City Nursing Home Management System** is a Java-based GUI application developed using NetBeans IDE. It provides a user-friendly interface for managing nursing home operations, including user authentication, patient booking, and administrative tasks. The system is designed to streamline processes for nursing home staff, managers, and administrators. 🩺💻

## ✨ Features

- **🔐 Login System**: Secure login for employees with fields for Employee ID, Username, and Password.
- **📅 Patient Booking Details**: View and manage patient details with options to add new patients and search existing records.
- **📊 Manager Dashboard**: Options to create new accounts, view patient details, and manage doctor accounts.
- **🛠️ Administrator Panel**: Tools for managing users and accounts within the system.
- **🖥️ User-Friendly Interface**: Intuitive navigation with "Back to Main" buttons for easy transitions between screens.

## 🛠️ Prerequisites

- **☕ Java Development Kit (JDK)**: Version 8 or higher.
- **🖥️ NetBeans IDE**: Version 8.2 or later (used for development).
- **🎨 Java Swing**: For GUI components (included in JDK).

## ⚙️ Setup Instructions

1. **📥 Clone the Repository**

   ```bash
   git clone https://github.com/DPramuditha/City-nursing-home-NetBeans-GUI.git
   ```

2. **📂 Open in NetBeans**

   - Launch NetBeans IDE. 🚀
   - Select `File > Open Project`.
   - Navigate to the cloned repository folder and open the project.

3. **🏗️ Build the Project**

   - Right-click the project in NetBeans and select `Build` to compile the code. 🛠️

4. **🚀 Run the Application**

   - Right-click the project and select `Run` to start the application.
   - The main login screen will appear. 🎉

## 📖 Usage

1. **🔑 Login to the System**

   - On the main screen, click "Login to System".
   - Enter your Employee ID, Username, and Password, then click "Login". ✅

2. **📅 Manage Patient Details**

   - From the main screen, select "All Patient Booking Details".
   - Add new patients or search for existing ones using the provided options. 🔍

3. **📊 Manager Dashboard**

   - After logging in, access the Manager Dashboard to create new accounts or view patient details. 📈

4. **👨‍💼 Administrator Functions**

   - Access the Administrator panel to manage users and accounts. 🛠️
